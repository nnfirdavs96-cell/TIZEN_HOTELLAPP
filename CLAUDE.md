# Инструкции для Claude Code в этом репозитории

## Обязательное правило: NAVIGATION.md

В корне репозитория есть [`NAVIGATION.md`](./NAVIGATION.md) — карта проекта: какая папка/файл за что отвечает,
и журнал изменений по PR/мержам. Она нужна, чтобы новый разработчик (или другой агент) не искал вслепую по коду.

**При любом изменении, которое добавляет, удаляет или значимо меняет файлы в `apps/`, `packages/`, `infra/`
(или структуру репозитория в целом), перед завершением задачи обязательно:**

1. Обнови таблицу структуры репозитория (раздел 1 `NAVIGATION.md`) — статусы ✅/⏳/❌.
2. Добавь/обнови запись в файловом индексе (раздел 3) для новых или значимо изменённых файлов —
   назначение файла + ключевые строки/блоки (не построчно, а по смысловым кускам).
3. Добавь запись в Changelog (раздел 4): дата, что изменилось, затронутые пути, ветка/PR.

Правки только в `docs/*.md` или `README.md` без изменений кода — обновлять `NAVIGATION.md` не обязательно,
если структура папок/файлов не поменялась.

Не пропускай этот шаг даже для небольших PR — это единственный способ держать карту проекта живой.
