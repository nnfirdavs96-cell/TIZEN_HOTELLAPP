# 18. Бэклог (тикеты)

Детализация роадмапа ([07](./07-roadmap.md)) до уровня тикетов: каждый со **списком работ**, **критериями приёмки (AC)**, **зависимостями** и **оценкой** (д — дней команды). Готово к заведению в GitHub Issues. ID: `HGA-<номер>`. Метки: `epic:*`, `module:*`, `phase:*`, `P0/P1/P2`.

Эпики: `INFRA`, `AUTH`, `TV-CORE`, `BOOKING`, `FOOD`, `SHOP`, `TAXI`, `CHAT`, `INFO`, `PAY`, `PMS`, `PANEL`, `OBSERV`, `RELEASE`.

## Definition of Ready (тикет можно брать в спринт)
- Есть описание, AC, оценка, зависимости разрешены.
- Для UI — есть макет/вайрфрейм ([16](./16-screens.md)).
- Для API — есть контракт в [15](./15-api-reference.md)/`shared-types`.
