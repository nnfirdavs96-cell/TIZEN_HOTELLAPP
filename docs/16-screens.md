# 16. Экраны: вайрфреймы и порядок фокуса

Подробное описание каждого экрана: назначение, ASCII-вайрфрейм (10-foot UI), **порядок фокуса** (D-pad), реакции на OK/Back, состояния (загрузка/ошибка/офлайн/пусто). Это убирает абстрактность модулей из [03](./03-modules.md) — отсюда можно верстать.

Обозначения: `[ кнопка ]` фокусируемый элемент · `‹›` текущий фокус · `↑↓←→` навигация · `OK` подтверждение · `BACK` назад (10009).

## TV-приложение

### S0 — Lock / Приветствие
```
┌──────────────────────────────────────────────┐
│                                                │
│              Добро пожаловать                  │
│            Отель «Пример», номер 305           │
│                                                │
│            ‹[  Войти (OK)  ]›                   │
│                                                │
│        Язык:  [ Рус ]   [ Eng ]                │
└──────────────────────────────────────────────┘
```
- **Фокус по умолчанию:** «Войти». **Порядок:** Войти → Рус → Eng (↓/→).
- **OK на «Войти»** → S1. **OK на языке** → переключение, сохранение на устройстве.
- **BACK** → диалог «Выключить приложение?» (только здесь).
- Номер комнаты берётся из провижининга (устройство уже привязано).

### S1 — Авторизация (PIN / код брони)
```
┌──────────────────────────────────────────────┐
│  Введите PIN или код брони                     │
│                                                │
│        ┌───┬───┬───┐                           │
│        │ 1 │ 2 │ 3 │     PIN: ● ● ● _           │
│        ├───┼───┼───┤                           │
│        │ 4 │ 5 │ 6 │     [ Очистить ]           │
│        ├───┼───┼───┤                           │
│        │ 7 │ 8 │ 9 │     [ Войти ]              │
│        ├───┼───┼───┤                           │
│        │ ⌫ │ 0 │ ✓ │                           │
│        └───┴───┴───┘                           │
│  Не помните код? Обратитесь на ресепшен        │
└──────────────────────────────────────────────┘
```
- Своя экранная клавиатура (не системная). **Фокус:** «1». Сетка 3×4 навигируется ↑↓←→; справа — Очистить/Войти.
- **Ошибка:** неверный код → тряска поля + «Неверный код, попыток осталось: N».
- **Блокировка:** после лимита → «Попробуйте через M минут» (423 PIN_LOCKED).
- **Успех** → S2.

### S2 — Главное меню (6 модулей)
```
┌──────────────────────────────────────────────┐
│ Здравствуйте, Иван!            Номер 305  🌐ru │
├──────────────────────────────────────────────┤
│   ‹┌────────┐›  ┌────────┐  ┌────────┐         │
│    │  🍽    │   │  🛍    │   │  🚕    │         │
│    │  Еда   │   │ Магазин│   │ Такси  │         │
│    └────────┘   └────────┘   └────────┘         │
│    ┌────────┐  ┌────────┐  ┌────────┐          │
│    │  💬    │   │  ℹ️    │   │  🧾    │          │
│    │ Связь  │   │ Инфо   │   │ Счёт   │          │
│    └────────┘   └────────┘   └────────┘          │
└──────────────────────────────────────────────┘
```
- **Фокус:** «Еда». Сетка 3×2, навигация ↑↓←→ (spatial). **OK** → экран модуля.
- **BACK** на главном → S0 (выход в Lock, но сессия активна).
- Бейдж непрочитанного на «Связь» при новом сообщении (WS).

### S3 — Еда: категории
```
┌──────────────────────────────────────────────┐
│ ← Еда                                  Корзина:│
│                                        ‹[🛒 2]›│
├──────────────────────────────────────────────┤
│ ‹[ Завтраки ]›  [ Горячее ]  [ Напитки ]       │
├──────────────────────────────────────────────┤
│ ┌──────┐ Омлет с овощами              450 ₽   │
│ │ фото │ 3 яйца, перец, томаты      ‹[ + ]›    │
│ └──────┘                                       │
│ ┌──────┐ Сырники                     390 ₽    │
│ │ фото │ со сметаной                  [ + ]    │
│ └──────┘                                       │
└──────────────────────────────────────────────┘
```
- **Фокус:** первая категория (или восстановленный). Вкладки категорий ← →; список ↑↓.
- Карточки виртуализированы; картинки ленивые (плейсхолдер).
- **OK на «+»** → быстрое добавление; **OK на карточке** → S4 (детали).
- **Корзина** (вверху справа) доступна с любого места (например, по кнопке).
- **Недоступна по времени:** категория «Завтраки» после 11:00 — затемнена, бейдж «с 06:00».

### S4 — Еда: карточка блюда
```
┌──────────────────────────────────────────────┐
│ ← Омлет с овощами                              │
│ ┌────────────┐  3 яйца, перец, томаты          │
│ │   фото     │  Аллергены: яйцо                 │
│ └────────────┘  Цена: 450 ₽                     │
│ Дополнительно:                                  │
│   ‹[ ☐ Сыр +80 ₽ ]›  [ ☐ Бекон +120 ₽ ]        │
│ Количество:  [ − ]  2  [ + ]                    │
│ Комментарий: [ без томатов            ]         │
│              ‹[  Добавить в корзину — 1060 ₽ ]› │
└──────────────────────────────────────────────┘
```
- **Порядок:** модификаторы → −/qty/+ → комментарий → «Добавить». Сумма пересчитывается на лету.
- **OK на «Добавить»** → корзина обновлена, возврат в S3 (тост «Добавлено»).

### S5 — Корзина
```
┌──────────────────────────────────────────────┐
│ ← Корзина                                      │
│ Омлет с овощами ×2 (Сыр)          1060 ₽       │
│        ‹[ − ]› 2 [ + ]   [ Удалить ]           │
│ Капучино ×1                        220 ₽       │
│         [ − ] 1 [ + ]   [ Удалить ]            │
│ ───────────────────────────────────────        │
│ Итого: 1280 ₽                                   │
│ Комментарий к заказу: [ Постучите        ]      │
│              ‹[   Оформить заказ   ]›           │
└──────────────────────────────────────────────┘
```
- Пустая корзина: «Корзина пуста» + «Перейти в меню».
- **OK «Оформить»** → S6.

### S6 — Оформление и оплата
```
┌──────────────────────────────────────────────┐
│ ← Оформление заказа                            │
│ Итого: 1280 ₽                                   │
│ Способ оплаты:                                  │
│   ‹(•) На счёт номера›   ( ) Онлайн (QR)         │
│ Время: (•) Как можно скорее  ( ) Ко времени     │
│                                                 │
│              ‹[   Подтвердить   ]›              │
└──────────────────────────────────────────────┘
```
- **На счёт номера** → `POST /orders paymentMethod=room` → S7.
- **Онлайн** → показать **QR** (payUrl), ждать вебхук → при оплате → S7.
- **Офлайн:** «Нет сети — заказ отправится автоматически» (в очередь), показать статус «отправляется».

### S7 — Статус заказа (realtime)
```
┌──────────────────────────────────────────────┐
│ Заказ #A-102 принят                            │
│  ● Новый → ● Принят → ◉ Готовится → ○ Везут → ○ │
│                                                 │
│  Примерно 20 минут                              │
│            ‹[ В меню ]›   [ Мои заказы ]         │
└──────────────────────────────────────────────┘
```
- Прогресс обновляется по WS `order.updated`. Статусы подсвечиваются.
- **BACK** → S2; заказ продолжает обновляться (бейдж).

### S8 — Магазин
Структура идентична S3–S7 (переиспользование компонентов): категории → товар (с остатком) → корзина → оформление (`kind=shop`) → статус. На карточке товара — «В наличии: N»; при `stock=0` — «Нет в наличии», кнопка неактивна.
```
┌──────────────────────────────────────────────┐
│ ← Магазин          [ История покупок ]  [🛒 1] │
│ ‹[ Гигиена ]› [ Сувениры ] [ Аренда ]          │
│ ┌──────┐ Зубной набор   150 ₽  В наличии: 20   │
│ │ фото │                       ‹[ + ]›         │
│ └──────┘                                       │
└──────────────────────────────────────────────┘
```

### S9 — Такси
```
┌──────────────────────────────────────────────┐
│ ← Такси                                        │
│ Откуда: Отель «Пример» (по умолчанию)          │
│ Куда:  ‹[ Аэропорт Шереметьево        ]›       │
│   Быстрый выбор: [ Аэропорт ] [ Вокзал ] [ Центр ]│
│ Класс: ‹(•) Стандарт› ( ) Комфорт ( ) Минивэн   │
│ ───────────────────────────────                 │
│ Оценка: ~1500 ₽ · подача ~7 мин                 │
│              ‹[   Заказать   ]›                 │
└──────────────────────────────────────────────┘
```
- Поле «Куда» открывает экранную клавиатуру / быстрые точки.
- После оценки (`/estimate`) показываются цена/ETA (или «уточняется» в dispatch-режиме).
- **OK «Заказать»** → S10.

### S10 — Статус такси
```
┌──────────────────────────────────────────────┐
│ Машина назначена                               │
│  Hyundai Solaris, белый · А123ВС777            │
│  Подача через 4 мин                             │
│  ● Заявка → ◉ Назначена → ○ Подъехала           │
│            ‹[ Отменить ]›   [ В меню ]          │
└──────────────────────────────────────────────┘
```
- Dispatch-режим: «Заявка передана ресепшену, ожидайте» + статус двигает персонал.

### S11 — Связь: меню
```
┌──────────────────────────────────────────────┐
│ ← Связь с отелем                               │
│  ‹[ 💬 Чат с ресепшен ]›                        │
│  [ 🧹 Уборка ]  [ 🧺 Полотенца ]  [ 🔧 Техник ] │
│  [ 🔕 Не беспокоить ]  [ 📞 Перезвоните мне ]   │
│  [ 📲 Позвонить ]   ← скрыто, если нет WebRTC   │
└──────────────────────────────────────────────┘
```
- Плитки сервис-запросов → подтверждение → статус.
- «Позвонить» рендерится только при `capabilities.webrtc` (ADR-005), иначе скрыта.

### S12 — Чат
```
┌──────────────────────────────────────────────┐
│ ← Чат с ресепшен                               │
│  ┌────────────────────────────────────┐        │
│  │ Гость: Можно доп. подушку?  10:02   │        │
│  │ Ресепшен: Конечно, принесём  10:03  │        │
│  └────────────────────────────────────┘        │
│  Сообщение: ‹[ ____________________ ]›  [ ▶ ]   │
└──────────────────────────────────────────────┘
```
- Лента ↑↓ (история подгружается), поле ввода → экранная клавиатура → «Отправить».
- Новое сообщение по WS появляется снизу; индикатор «печатает».
- Сбой отправки → значок «!», повтор по OK.

### S13 — Информация
```
┌──────────────────────────────────────────────┐
│ ← Информация                                   │
│  ‹[ 🍽 Расписания ]› [ 🗺 Карта отеля ]         │
│  [ 🏛 Рядом ]  [ 📶 Wi-Fi ]  [ 📋 Правила ]     │
│  [ ☎ Контакты ]                                 │
└──────────────────────────────────────────────┘
```
- Все подэкраны работают **офлайн** (из кэша). Расписания — таблица; карта — изображение-схема; «Рядом» — карточки POI.

### S14 — Счёт / Check-out
```
┌──────────────────────────────────────────────┐
│ ← Счёт и выезд                                 │
│  Заказ еды #A-102 .................. 1060 ₽    │
│  Магазин #S-44 ..................... 1400 ₽    │
│  ────────────────────────────────────          │
│  Итого: 2460 ₽                                  │
│  Email для счёта: ‹[ ivan@example.com ]›        │
│         [ Оформить выезд и отправить счёт ]     │
└──────────────────────────────────────────────┘
```
- **OK «Оформить выезд»** → `/booking/checkout` → экран «Счёт отправлен, спасибо!» → (опц.) короткий опрос CSAT → выход в S0, сессия закрыта.

### Глобальные состояния (любой экран)
- **Загрузка:** скелетоны/спиннер с таймаутом, не «вечный».
- **Нет сети:** баннер сверху «Нет соединения — повтор автоматически»; мутации в очереди.
- **Ошибка сервера:** «Что-то пошло не так» + [ Повторить ].
- **Пусто:** дружелюбный пустой стейт с подсказкой действия.

## Панель персонала (десктоп, мышь+клавиатура)

### P0 — Вход
Email + пароль → по роли открывается стартовый раздел (kitchen → Заказы, reception → Чаты/Заявки, admin → Дашборд).

### P1 — Заказы (kitchen / reception)
```
┌─────────────────────────────────────────────────────────┐
│ Заказы   [ Новые(3) ] [ В работе ] [ Готовые ]   🔔       │
├──────────────┬──────────────┬──────────────┬─────────────┤
│ #A-102 ·305  │ #A-101 ·210  │ #A-099 ·305  │             │
│ ⏱ 1:35 🔴    │ ⏱ 4:10 🟠    │ Готовится    │             │
│ Омлет ×2(Сыр)│ Капучино ×1  │ Паста ×1     │             │
│ без томатов  │              │              │             │
│ 1060 ₽       │ 220 ₽        │ 540 ₽        │             │
│[Принять]     │[Готовится]   │[Везут][Готов]│             │
└──────────────┴──────────────┴──────────────┴─────────────┘
```
- Канбан по статусам; цвет/звук по времени ожидания; кнопки двигают статус (WS гостю).

### P2 — Чаты (reception)
Список номеров с непрочитанными слева; справа — переписка + поле ответа; индикатор онлайн TV.

### P3 — Заявки (reception/housekeeping/maintenance)
Лента сервис-запросов, фильтр по роли/статусу; «Взять в работу» / «Выполнено»; callback-запросы с телефоном.

### P4 — Номера (reception)
Таблица: номер, статус, выезд, открытые заявки, онлайн TV (`last_seen`).

### P5 — Контент (admin)
CRUD меню/магазина/инфо: формы RU/EN, загрузка изображений, переключатель «опубликовано», стоп-лист/остатки. Изменения видны на TV без переустановки.

### P6 — Дашборд/Аналитика (admin)
Выручка по источникам, число заказов, топ-блюда, заявки по типам, среднее время ответа в чате (см. [21](./21-analytics-i18n.md)).

## Принципы фокуса (сводно для TV)
- На каждом экране — определён **первый фокус** и **порядок** (документирован выше).
- При возврате (BACK) — **восстанавливается** прежний фокус родительского экрана.
- Модалки/QR — **focus trap** (фокус не уходит за пределы).
- Любой `:focus` визуально заметен (рамка + лёгкий масштаб), цель ≥ 48 px, учёт overscan ~5%.
