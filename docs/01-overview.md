# 01. Обзор проекта

## Видение

**Hotel Guest App** — интерактивное приложение на Samsung Smart TV (Tizen) в каждом номере отеля. Гость управляет всеми сервисами отеля с пульта телевизора: регистрация и выезд, заказ еды, вызов такси, покупки, связь с персоналом, информация об отеле. Цель — заменить звонки на ресепшен и бумажные папки «room directory» одним удобным экраном.

## Ценность

| Для кого | Ценность |
|----------|----------|
| **Гость** | Всё в одном месте на большом экране, без приложений и звонков; круглосуточно; на своём языке |
| **Отель** | Снижение нагрузки на персонал, меньше ошибок в заказах, современный имидж |
| **Бизнес (мы)** | SaaS-подписка за номер + комиссия с заказов + реклама партнёров |

## Цели проекта (бизнес)

1. Запустить MVP и поставить его в **1–2 пилотных отеля** в течение ~6–8 месяцев.
2. Доказать снижение нагрузки на ресепшен и рост заказов room-service через приложение.
3. Получить кейсы/референсы для масштабирования (прямые продажи + партнёрства с PMS).

## Пользователи (персоны)

| Персона | Кто | Контекст использования | Ключевые потребности |
|---------|-----|------------------------|----------------------|
| **Гость** | Постоялец номера, 25–65 лет, разный тех. уровень | Лежит/сидит в 2–3 м от TV, управляет пультом | Простота, крупный шрифт, родной язык, быстрый отклик |
| **Ресепшен** | Сотрудник стойки | За компьютером, много номеров одновременно | Видеть запросы/чаты/заказы, быстро реагировать |
| **Кухня / room-service** | Повар, официант | На кухне, у экрана/планшета | Очередь заказов, статусы, состав блюд |
| **Хаускипинг** | Горничные, техники | По заявкам | Список заявок по номерам, отметка «выполнено» |
| **Администратор** | Менеджер отеля | Настройка | Меню, цены, расписания, аналитика, пользователи |

## Объём MVP (что входит / что нет)

**Входит в MVP (Фазы 1–3):**
- Авторизация по номеру + PIN, Check-in/Check-out.
- Заказ еды в номер с оплатой «на счёт номера».
- Магазин отеля.
- Чат с персоналом + сервисные запросы (уборка, полотенца, техник).
- Вызов такси (через одного провайдера/диспетчерскую).
- Информация об отеле (расписания, карта, Wi-Fi, достопримечательности).
- Панель персонала (ресепшен, кухня, хаускипинг, админ).
- Языки RU/EN.

**Не входит в MVP (бэклог /後 later):**
- Полноценный VoIP-видеозвонок на всех TV (только аудио на новых + запрос обратного звонка).
- Глубокая двусторонняя интеграция с PMS в реальном времени (в MVP — экспорт счёта).
- Онлайн-оплата картой на самом TV (только charge-to-room; онлайн — через QR на телефон).
- Мобильное приложение гостя.
- Более 2 языков, мультивалютность сверх базовой.

## Метрики успеха (KPI)

### Продуктовые
- **Adoption:** ≥ 40% гостей открывают приложение хотя бы раз за проживание (пилот).
- **Снижение звонков на ресепшен:** −20% сервисных звонков в пилотном отеле.
- **Конверсия в заказ:** ≥ 15% сессий «Еда» заканчиваются заказом.
- **Среднее время ответа персонала в чате:** < 2 мин в рабочие часы.
- **CSAT:** ≥ 4.3 / 5 по опросу на экране выезда.

### Технические
- **TTI (Time To Interactive)** на TV 2017 года: < 3 c.
- **Доступность API (uptime):** ≥ 99.5%.
- **Доля упавших заказов из-за сети:** < 1% (за счёт офлайн-очереди).
- **P95 latency REST:** < 400 мс.
- **Краши TV-приложения:** < 0.5% сессий.

## Ограничения и допущения

- Целевые устройства — Samsung Tizen TV 2017+; обязательная поддержка моделей 2017–2019 (ограниченная RAM).
- В номере есть стабильный Wi-Fi/Ethernet, но возможны кратковременные потери сети.
- У отеля уже есть PMS (Opera/Fidelio/1С-отель) — но в MVP глубокая интеграция не гарантируется.
- Платёжная логика опирается на фолио отеля, а не на хранение карт у нас.
- Языки запуска — RU и EN; архитектура i18n позволяет добавлять языки без переписывания.

## Глоссарий

| Термин | Значение |
|--------|----------|
| **Tizen** | ОС Samsung Smart TV; приложения — это Web Apps (HTML/CSS/JS) |
| **D-pad** | Крестовина пульта (вверх/вниз/влево/вправо) + OK |
| **Фолио (folio)** | Счёт гостя в PMS, куда добавляются начисления; «charge-to-room» = списать на фолио |
| **PMS** | Property Management System — система управления отелем (Opera, Fidelio, 1С-отель) |
| **Провижининг** | Привязка конкретного TV к конкретному номеру комнаты |
| **SSSP** | Samsung Smart Signage Platform — корпоративный режим Business TV |
| **WGT** | Формат пакета Tizen Web-приложения (`.wgt`) |
| **Фокус** | Текущий выбранный пультом элемент на экране (CSS `:focus`) |
