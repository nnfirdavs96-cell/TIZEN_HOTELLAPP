# 12. Монетизация

Из исходного плана с уточнениями под архитектуру (charge-to-room, мультитенантность, аналитика).

## Источники дохода

| Модель | Описание | Ориентир |
|--------|----------|----------|
| **SaaS-подписка** | Ежемесячная плата за каждый активный номер | $5–15 / номер / мес → 100 номеров = $500–1500/мес |
| **Комиссия с заказов** | % с заказов еды, такси, магазина (через charge-to-room/онлайн) | 5–15% от суммы |
| **Реклама / партнёрства** | Локальные рестораны, турагентства, магазины, экскурсии | Фиксированная плата за размещение |

Модели **комбинируются**. Для пилота возможен сниженный/нулевой тариф ради кейса.

### Связь с архитектурой
- **Комиссию** удобно считать из `folio_entries`/`orders` по `hotel_id` — аналитика уже собирает суммы по источникам ([04](./04-data-model.md)).
- **Подписка** — по числу `devices` со статусом `active`/`provisioned` на отель (мультитенантность по `hotel_id`).
- **Реклама** — как тип контента в модуле «Информация»/партнёрские карточки (без ущерба UX; помечать как партнёрское).

## Ценообразование (гипотезы для проверки на пилоте)

| Сегмент | Подписка | Комиссия | Примечание |
|---------|----------|----------|------------|
| Малый отель (< 50 номеров) | выше за номер | средняя | Меньше эффект масштаба |
| Средний (50–150) | базовая | базовая | Основной сегмент |
| Крупный/сеть (150+) | ниже за номер | ниже + индив. | Объём + интеграция с PMS |

Метрики юнит-экономики для проверки: ARPU на номер, доля номеров с заказами, средний чек, конверсия в заказ ([01](./01-overview.md#метрики-успеха-kpi)).

## Стратегия выхода на рынок (GTM)

1. **Пилот:** 1–2 отеля (возможно бесплатно/со скидкой), собрать отзывы и кейс.
2. **Доработка:** по обратной связи пилота закрыть P1-бэклог, отполировать UX.
3. **Референсы:** оформить кейсы (снижение нагрузки на ресепшен, рост room-service).
4. **Масштабирование:**
   - Прямые продажи отелям (демо на реальном TV).
   - **Партнёрства с PMS** (Opera, Fidelio, 1С-Отель) — интеграция как канал дистрибуции.
   - Партнёрства с поставщиками гостиничных TV / системными интеграторами Samsung Business.

## Что усиливает монетизацию (продуктовые рычаги)

- **Аналитика для отеля** (популярные блюда, частые запросы, выручка) — повышает ценность подписки.
- **Простое самонаполнение контента** (админ-панель) — снижает стоимость онбординга нового отеля.
- **Партнёрские карточки** (рестораны/экскурсии) — дополнительный доход без ущерба основному UX.
- **Мультиязычность** — расширяет рынок (туристические локации).

## Ограничения и честность

- Рекламу и партнёрские размещения помечать прозрачно, не вредить пользовательскому опыту гостя.
- Комиссия не должна задваивать начисления гостю — она берётся с отеля/партнёра, а не «сверху» на гостя без согласования.
- Цифры дохода — ориентировочные гипотезы, проверяются на пилоте перед масштабированием.
