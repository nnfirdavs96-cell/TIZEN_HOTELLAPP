# Hotel Guest App 🏨📺

**Интерактивное приложение для гостей отеля на Samsung Smart TV (Tizen).**
Гость управляет всеми сервисами отеля прямо с пульта телевизора в номере — без звонков на ресепшен и установки мобильных приложений.

> **Статус проекта:** 📋 Планирование / Pre-development.
> Кода ещё нет — этот репозиторий содержит **полную проектную документацию и план разработки**. Реализация начинается с Фазы 1 (см. роадмап).

## 🧩 Что делает приложение

Шесть модулей, разрабатываемых поэтапно:

1. **🛎 Check-in / Check-out** — цифровая регистрация по QR/коду брони, авторизация по номеру комнаты + PIN, счёт на email при выезде.
2. **🍽 Заказ еды в номер** — меню с фото, корзина, оплата, статус заказа в реальном времени.
3. **🚕 Вызов такси** — интеграция с агрегаторами/диспетчерскими, выбор класса, время и стоимость, уведомление о прибытии.
4. **🛍 Магазин отеля** — сувениры, гигиена, аренда; доставка в номер, добавление к счёту.
5. **💬 Связь с персоналом** — чат с ресепшен (WebSocket), запросы (уборка, полотенца, техник), звонок (см. ADR по VoIP).
6. **ℹ️ Информация об отеле** — расписания (ресторан, спа, бассейн), карта, достопримечательности, Wi-Fi, правила.

## 🚀 Быстрый старт (для разработчика)

> Пока заглушка — команды появятся вместе с кодом в Фазе 1. Зафиксировано здесь как целевой контракт.

```bash
# 1. Зависимости (монорепозиторий, pnpm workspaces)
pnpm install

# 2. Поднять инфраструктуру (PostgreSQL + Redis) локально
docker compose -f infra/docker/docker-compose.dev.yml up -d

# 3. Применить миграции и сиды
pnpm --filter api db:migrate && pnpm --filter api db:seed

# 4. Запустить бэкенд
pnpm --filter api dev

# 5. Запустить панель персонала
pnpm --filter staff-panel dev

# 6. TV-приложение — собрать .wgt и запустить в эмуляторе Tizen Studio
pnpm --filter tv-app build
# далее: Tizen Studio → Run на Samsung TV Emulator
```

Полная инструкция по окружению разработчика — в [docs/06-tizen.md](./docs/06-tizen.md) и [docs/10-deployment-ops.md](./docs/10-deployment-ops.md).

## 🛠 Технологический стек

| Компонент | Технология | Почему |
|-----------|-----------|--------|
| TV-приложение | **Vanilla HTML5 + CSS3 + JS (TS)** | Старые TV имеют ~512 МБ–1 ГБ RAM; тяжёлые SPA-фреймворки рискованны |
| Бэкенд | **Node.js + NestJS (TypeScript)** | Единый язык со фронтендом, общие типы; альтернатива — Python FastAPI (см. ADR-001) |
| База данных | **PostgreSQL** | Реляционные данные: гости, брони, заказы |
| Кэш / реальное время | **Redis** | Сессии, очереди уведомлений, pub/sub |
| Панель персонала | **React.js + TypeScript** | Богатый UI на десктопе ресепшена |
| Реальное время | **WebSocket (Socket.IO)** | Чат, статусы заказов, уведомления |
| Авторизация | **JWT (access + refresh)** | Авторизация по номеру комнаты |
| Платежи | **Charge-to-room (folio) + провайдер с токенизацией** | На TV небезопасно вводить карту; PCI-минимизация (см. ADR-004) |
